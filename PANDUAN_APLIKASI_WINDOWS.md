# 🖥️ Panduan Lengkap Aplikasi Installer Windows Masayume LMS & CBT

Paket instalasi resmi Windows (**Model 2: Full Setup Installer**) untuk sistem **MASAYUME (`https://masayume.id`)** telah selesai dibuat dan siap dibagikan kepada pengguna, Sensei, maupun siswa.

File installer utama berada di:
📁 **`windows-app/Masayume-LMS-Setup.exe`**

---

## 🚀 1. Cara Instalasi untuk Pengguna / Siswa

Siapa pun yang ingin memasang aplikasi di komputernya cukup melakukan langkah mudah ini:

1. **Unduh / Buka file**:
   👉 **`Masayume-LMS-Setup.exe`** (Ukuran sangat hemat: ~74 KB).
2. **Jendela Setup Wizard Masayume akan terbuka**:
   - **Halaman 1 (Selamat Datang)**: Klik **Lanjut >**.
   - **Halaman 2 (Pilih Lokasi)**: Secara default terpasang di folder program pengguna lokal. Klik **Lanjut >**.
   - **Halaman 3 (Opsi Pintasan)**: Centang `Buat jalan pintas di Layar Desktop` dan `Start Menu`. Klik **Pasang**.
   - **Halaman 4 (Progress)**: Setup mengekstrak berkas dan mendaftarkan aplikasi secara resmi ke sistem Windows.
   - **Halaman 5 (Selesai)**: Centang `Jalankan MASAYUME LMS & CBT sekarang`, lalu klik **Selesai**.
3. Ikon resmi **MASAYUME - LMS & CBT** akan langsung muncul di **Desktop** dan **Start Menu**.

---

## 🌟 2. Mengapa Model Installer Ini Lebih Mudah Dipahami?

1. **Satu File Setup Mandiri (`.exe`)**:
   Tidak memerlukan file script tambahan, tidak perlu file `.bat`, dan tidak perlu download runtime berat. Cukup kirim 1 file `Masayume-LMS-Setup.exe` (bisa lewat WhatsApp, Flashdisk, Google Drive, dll).
2. **Terdaftar Resmi di Windows**:
   Aplikasi tercatat resmi di **Windows Settings > Apps > Installed apps** (atau **Control Panel > Programs and Features**) dengan nama *MASAYUME - LMS & CBT Terpadu LPK Penyaluran Jepang*.
3. **Mendukung Fitur Uninstall Resmi**:
   Jika suatu saat ingin menghapus aplikasi, pengguna cukup mengklik **Uninstall** melalui Control Panel Windows atau menjalankan `uninstall.exe`.
4. **Sesi Belajar & CBT Mandiri**:
   Login siswa dan guru tersimpan permanen di PC tanpa terganggu riwayat browsing pribadi.
5. **Live Cloud Synchronization**:
   Aplikasi otomatis selalu sinkron dengan server web hosting `https://masayume.id` secara realtime.

---

## 🎛️ 3. Pintasan Tombol Keyboard Saat Menggunakan Aplikasi:
* **F11**: Masuk / Keluar Mode Layar Penuh (*Fullscreen CBT Exam Mode*).
* **F5**: Muat ulang halaman (*Refresh*).
* **Ctrl +**: Memperbesar tampilan teks soal / modul.
* **Ctrl -**: Memperkecil tampilan teks.
* **Ctrl 0**: Mengembalikan ukuran normal (100%).
